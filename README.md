# Honey Glow Website

A responsive, single-page Honey Glow product website in a luxury black-and-yellow theme.

## Before publishing
1. Open `index.html`.
The WhatsApp ordering button is already configured with the business number supplied by the owner.

The product price is set to R479. Product ingredients and specific claims have not been invented; add only verified details from the product packaging.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `honey-glow`.
2. Upload `index.html` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish. Your address will look like `https://YOUR-USERNAME.github.io/honey-glow/`.

This is a static website. WhatsApp ordering opens a pre-filled message; it does not process card payments or automatically manage stock.
